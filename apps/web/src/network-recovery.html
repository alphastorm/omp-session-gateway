OMP Sessions troubleshooting

Still unreachable?

Restart the browser after a network change

Android Chrome can rarely stop networking after the phone locks or changes networks. OMP Sessions cannot restart the browser process itself. If other Chrome pages also fail while the phone is online:

  1. Open Android Settings, then Apps.
  2. Select the browser that hosts OMP Sessions and tap Force stop.
  3. Reopen OMP Sessions from the home screen.
  4. If it remains unavailable, confirm Tailscale is connected and the desktop is awake.

These steps are guidance, not a diagnosis: the same banner can also mean the tailnet, desktop, or gateway is genuinely unavailable.
